Add a function to the existing backend that takes the parsed spreadsheet rows (already extracted from an Opay Excel statement) and transforms them into a compact summary suitable for sending to an LLM. Do not call any AI API yet — just build and return this formatted object from the /api/analyze endpoint for now.

The spreadsheet has this exact structure:

Row 2: Account Name, Account Number
Row 4: Opening Balance, Total Debit
Row 5: Closing Balance, Total Credit
Row 7: header row — Trans. Date | Value Date | Description | Debit(₦) | Credit(₦) | Balance After(₦) | Channel | Transaction Reference
Row 8 onward: transaction data, where empty debit/credit cells contain the string "--" instead of being blank

Build a function that does the following:

Extract the summary block: openingBalance, closingBalance, totalDebit, totalCredit from their fixed cell positions (rows 4-5), stripping the ₦ symbol and commas before converting to numbers.
Parse each transaction row (row 8 onward) into { date, description, amount, type }:
date = the Value Date column
description = the full original description text, unmodified — keep recipient names, bank/platform, and account numbers exactly as they appear (e.g. "Transfer to IFEANYI SAMUEL ONUKWUE | OPay | 8067524718" stays as-is)
amount = credit minus debit, treating "--" as zero and stripping commas from currency strings before converting to numbers
type = "credit" if credit > 0, else "debit"
Group transactions into simple spending categories based on keywords in the description: person-to-person transfers, POS payments, airtime/data, and an "other" catch-all. Sum the total amount per category.
Select up to 15 sample transactions, spread evenly across the statement period rather than just the first 15 rows, keeping full original descriptions with names intact.
Return a single JSON object shaped like:
json
{
  "summary": { "openingBalance": 0, "closingBalance": 0, "totalDebit": 0, "totalCredit": 0 },
  "categoryBreakdown": { "personTransfers": 0, "posPayments": 0, "airtimeData": 0, "other": 0 },
  "sampleTransactions": [{ "date": "", "description": "", "amount": 0 }]
}

This is purely a data transformation step — no AI calls, no changes to the frontend. Just make /api/analyze return this formatted JSON so it can be verified before wiring in the LLM.
